# ML Quest

Source of [jmb-python-developer.github.io](https://jmb-python-developer.github.io/): my machine-learning projects shown as levels on a game map.

Everything is generated from `levels.json`:

```bash
python3 build.py
```

This writes `index.html` (this site), the map image used in my [profile README](https://github.com/jmb-python-developer), and `build/readme-snippet.md` (the level details pasted into that README).
